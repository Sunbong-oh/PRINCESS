# 👑 Princess Talk

공주 그림을 보며 영어로 말해보는 어린이 말하기 놀이 웹게임.
**4살 · 6살 · 8살 · 12살** 난이도를 골라, 그림 속 장면에 대해 영어로 대답해요.

## 바로 열기

- 이미 GitHub Pages로 배포되어 있습니다: **https://sunbong-oh.github.io/PRINCESS/**
  (저장소 `Sunbong-oh/PRINCESS`, Settings → Pages → Branch: `main` / root)

## 무엇을 하나요

| 난이도 | 기대하는 대답 | 보기 카드 |
|---|---|---|
| 🐣 4살 | 한 단어 — `Five`, `Blue`, `Shell` | 단어 카드 3장 |
| 🌸 6살 | 짧은 표현 — `Five cups`, `Glass slipper` | 짧은 표현 카드 3장 |
| 👑 8살 | 짧은 문장 — `There are five cups on the table.` | 문장 카드 3장 |
| 💎 12살 | 8살과 같은 문장 — `She is wearing a blue dress.` | **보기 없음, 바로 말하기** + 💡 힌트 |

- **첫 화면 = 공주 6명 카드**: 백설공주·신데렐라·인어공주·잠자는 숲속의 공주·눈의 여왕 엘사·라푼젤
  여섯 장의 그림 카드를 바로 보여줍니다(모바일 2열 × 3행, 넓은 화면 3열 × 2행).
  카드에는 대표 그림(`assets/img/hero-*.webp`, `object-fit:contain`으로 잘림 없음), 한글·영어 이름,
  공주별 테마 컬러가 들어 있고, **카드(그림 포함)를 누르면 그 공주 10문제가 바로 시작**됩니다.
- **⭐ 오늘 추천**: 오늘 날짜로 정해진 공주 카드에만 작은 배지가 붙습니다. 게임 내용은 같고, 어떤 공주든 눌러서 시작하면 됩니다.
- **🎲 랜덤 골라줘**: 카드 그리드 아래의 작은 보조 버튼 — 6명 중 아무나 한 명으로 바로 시작합니다.
  결과 화면의 🎲 다른 공주 이야기는 직전 공주를 피해 고르고, 👑 공주 다시 고르기는 6장 카드로 돌아갑니다.
- **공주별 10문항, 총 60문항 / 한 판 10문제**: 6명 공주(백설·신데렐라·잠자는 숲속·라푼젤·엘사·인어공주)에
  각각 정확히 10문항씩 모두 60문항. 한 판은 **고른 공주 한 명의 10문항을 전부 섞어서** 내고,
  다른 공주 문항은 절대 섞지 않습니다. 공주를 바꿔 가면 6명 × 10문항 = 60문항을 겹치지 않고 다 풀 수 있고,
  같은 공주를 다시 고르면 그 10문항이 새 순서로 다시 나옵니다.
- **한 공주만**: 문제 화면 위 제목은 `잠자는 숲속의 공주 · 10문제`처럼 그 공주 이름만 씁니다.
- **질문 → A·B·C 낭독**: 질문을 다 읽고 잠깐 쉬면 `A. 보기`, `B. 보기`, `C. 보기`를 차례로 읽어줍니다.
  도중에 보기를 누르거나 🎤를 누르면 이어 읽던 낭독은 즉시 멈춥니다.
  낭독 속도는 난이도별로 다릅니다 — 4살 `0.68`, 6살 `0.75`, 8살 `0.82`, 12살 `0.90`, 보기는 그보다 0.04 더 느리게.
- **💎 12살 모드 (선택지 없이 바로 말하기)**: 보기 카드 대신 그림만 보고 영어 문장으로 바로 답합니다.
  문항은 8살 문장을 그대로 쓰므로 60문항이 모두 12살에서도 나옵니다. 질문만 자동으로 읽어주고(A·B·C 낭독 없음),
  안내 문구는 `선택지가 없어요! 🎤 말해보기를 눌러 영어로 바로 답해 보세요.`입니다.
  두 번 틀리면 보기가 없으니 정답 문장을 토스트(`This one! ⭐ …`)와 음성으로 알려 주고 다음 문제로 넘어갑니다.
- **💡 힌트**: 12살 모드에서만 보이는 골드 톤 버튼. 누르면 정답 문장을 화면에 쓰지 않고
  `0.85` 속도로 한 번 들려주고 `힌트! 방금 들린 문장을 영어로 말해 보세요 💡` 토스트를 띄웁니다.
  들은 문장을 그대로 따라 말하면 정답 처리(칭찬 + 스티커 + 다음 문제)입니다.
- **보기 버튼 하나 (🔊 포함)**: 보기 카드 오른쪽에 🔊 가 들어 있습니다.
  한 번 누르면 그 보기를 천천히 읽어주고 **선택 표시**만 하고, **한 번 더 누르면 정답 제출**입니다.
  🎤 로 말해서 답해도 됩니다. 음성인식 중에 보기를 누르면 인식을 먼저 멈추고 읽습니다.
- **관사 없이**: 4살·6살 보기는 `A`/`An` 없이 `Ball`, `Blue dress`처럼 씁니다. 음성 답은 `a ball`, `ball` 모두 정답.
- **말하기**: `SpeechRecognition`으로 아이의 영어 발음을 인식 (핵심 단어 조합 + 유사 발음 허용).
- **그림은 잘리지 않습니다**: 장면 그림을 `object-fit:contain`으로 띄워 어떤 화면(모바일·태블릿·데스크톱)에서도
  원본의 위·아래·좌·우가 잘리지 않고 전체가 보입니다. 그림 높이는 CSS 변수 `--scene-max`로 조절하고,
  장면 이름표는 그림을 가리지 않도록 그림 아래에 둡니다. 질문은 "화면에 보이는 것"만으로 답할 수 있게 맞춰 둡니다.
- 정답마다 폭죽 애니메이션 + 별·왕관 스티커를 모아요(localStorage 저장).

## 구성

```
index.html
manifest.json
assets/css/style.css
assets/js/data.js     ← 공주 6명 × 4장 그림, 공주별 10문항 총 60문항 × 난이도 3단계(12살은 8살 문장을 그대로)
assets/js/app.js      ← 화면 전환, 한 공주 10문제 뽑기, 음성, 채점, 스티커, 폭죽
assets/img/*.webp     ← 주인공 6장 + 장면 18장 (총 24장, 약 4.3MB)
```

## 퀴즈 데이터 고치기

`assets/js/data.js`의 각 문항은 아래 모양입니다.

```js
{
  img: 'assets/img/sw-2-mugs.webp',
  scene: '난쟁이 친구들',
  q: {
    4: Q('How many cups are on the table?', 'Five',
         ['Three', 'Five', 'Seven'],
         [['five', '5']],                  // 이 단어들 중 하나가 들리면 정답
         '탁자 위에 컵이 몇 개 있나요?'),
    // 6, 8 도 같은 구조
  }
}
```

`Q(text, answer, opts, keys, ko)` — `keys`는 "그룹의 배열"입니다. 그룹마다 하나 이상 일치해야
정답이므로 `[['five','5'], ['cup','mug']]`는 "five/five 중 하나" + "cup/mug 중 하나"가 모두 들려야 통과입니다.

한 장의 그림에 문항을 두 개 이상 붙일 수 있습니다(같은 그림, 다른 질문). 문항 수를 바꾸면
`app.js`의 `ROUND_SIZE`(한 판 문제 수)도 함께 보세요.

## 참고

- 삽화는 모두 AI 생성 이미지이며, 각 장면은 주인공 일러스트를 기준으로 편집해 화풍과 인물을 통일했습니다.
- 문제와 정답은 이미지 생성 프롬프트와 실제 그림 확인 기록에 근거해 맞춰 두었습니다.
  개수 세기 문항은 **화면에 크게 보이는 두 곳**(백설 컵 5개 - 탁자 위 한 줄, 인어 진주 3개 - 손에 든 조개 안)만 씁니다.
  사과 바구니(sw-3-apples)와 바닷속 물고기(lm-1-fish)는 그림 아랫부분이 잘리거나 물고기가 작아 아이가 세기 어렵다는
  지적에 따라, 개수 대신 "무엇을 들고 있나요 / 무엇이 함께 헤엄치나요"처럼 한눈에 보이는 것을 묻습니다.
  이미지를 교체하면 `data.js`의 정답도 함께 확인해 주세요.
- 잠자는 숲속의 공주 숲 장면(`sb-2-forest.webp`)은 토끼 대신 작은 요정(아기천사처럼 보임)이 보인다는
  피드백에 따라 토끼/동물 개수 문항을 모두 빼고 숲·장미로만 묻습니다.
- 낭독 속도는 `assets/js/app.js`의 `LEVEL_RATE`(4/6/8/12살)에서 조절합니다.
  보기 낭독은 그보다 0.04 더 느립니다(`optionRate()`).
- 스모크 테스트: `python3 work/princess-test/run_tests.py` (QuickJS + DOM 스텁, 실행마다 260여 개 검사 — 전부 통과).
  첫 화면 카드 그리드(6장 렌더링·힉1인 ⭐ 배지·카드별 10문제 시작·`object-fit:contain`·2/3열 규칙),
  12살 모드(레벨 버튼 4개·보기 숨김·힌트 낭독·질문만 낭독·2회 오답 처리)와
  캐시버스터(`?v=20261119g`)까지 확인합니다.
- 마이크(말하기)는 모바일 안드로이드 Chrome을 기준으로 다듬었습니다. 중간(interim) 결과라도 이미 정답이면
  `isFinal`을 기다리지 않고 바로 정답 처리하고, 최종 결과 없이 `onend`로 끝나면 마지막으로 들린 말로 채점합니다
  (그래서 무반응으로 끝나지 않습니다). `startListening()`마다 `SpeechRecognition`을 새로 만들고, `start()`는
  클릭 핸들러 안에서 동기로 부릅니다. 마이크 권한이 막히면 `Chrome 앱에서 열거나 보기를 눌러보세요` 안내를
  토스트와 힌트에 함께 보여줍니다.
- 한 판은 언제나 고른 공주 한 명의 10문항입니다(`pickRound()`). 어떤 공주로 시작해도
  10문제가 전부 같은 공주이고, 그 공주의 10문항이 한 문제도 빠지지 않고 나옵니다.
